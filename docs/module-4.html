4 Module 4

Module Focus: Relationships between quantitative variables

In this module, we learn to display the relationship between two quantitative variables with a scatterplot, describe that relationship in terms of form, direction, scatter and outliers, measure it numerically with the correlation coefficient, fit a regression line to make predictions, check that line with a residual plot, and recognise the cautions and precautions that come with regression analysis.

4.1 Introduction to Scatterplots

For two quantitative variables, we use a scatterplot.

Categorical variable Quantitative variable
Categorical variable Two-way table Boxplot
Quantitative variable Boxplot Scatterplot

Response and explanatory variables

  • A response (dependent) variable measures an outcome in the study
  • An explanatory (independent) variable explains or influences changes in the response variable, or is the variable expected to change when the explanatory variable is manipulated
  • The variable we are predicting goes on the y-axis and is the dependent variable; the explanatory variable goes on the x-axis

Example: if a study is looking at hours of study per week and final mark in STA1003, the explanatory variable is hours of study (x-axis) and the response variable is final mark (y-axis), since we are trying to predict the mark from the hours studied. In some cases it doesn’t matter which is which.

Interpreting a scatterplot visually

To describe a scatterplot, look at:

  • Form — is the pattern approximately linear (a straight line pattern), or curved?
  • Direction — only relevant if the form is linear. Two variables are positively associated if high values of one accompany high values of the other, and negatively associated if high values of one accompany low values of the other.
  • Scatter — the amount of scatter around the main form: small, moderate, or large. A stronger relationship has smaller scatter; a weaker relationship has larger scatter.
  • Outliers — a data point that does not fit the pattern. Outliers can be:
    • High leverage — unusual because its x-value is far from the mean of the x-values
    • Large residual — unusual because its y-value is far from the mean of the y-values
    • Influential — removing it from the analysis changes the model enough to make a meaningful difference

A high leverage outlier has the potential to change the regression line, but doesn’t always do so. What matters is whether it is influential. Arbitrarily deleting points can give a false sense of how well the model fits the data.

4.2 Correlation

Correlation measures the direction and strength of the linear relationship between two quantitative variables, and is measured using the correlation coefficient \(r\). Correlation is only relevant if the form is linear — always check the scatterplot first!

Properties of the correlation coefficient \(r\)

  • The sign of \(r\) indicates positive or negative association
  • \(r\) is always between \(-1\) and \(+1\)
  • \(r = 0\) means no linear relationship between the variables
  • \(r = +1\) means a perfect, positive relationship
  • \(r = -1\) means a perfect, negative relationship
  • \(r\) is not affected by changing the units of either variable (e.g. from cm to inches)
  • Strength is shown by the size of \(r\); direction is shown by the sign of \(r\)

Try it yourself. Drag the slider to set a target correlation, and watch a fresh random cloud of points redraw with roughly that correlation. Notice that the sample correlation of any particular cloud of points won’t exactly match the target — that’s sampling variability in action. Click “New sample” to draw another cloud at the same target and see how much it moves around.

4.3 Regression

Regression finds the “best” straight line for the data (using SPSS, Excel, or mathematical methods).

The regression line

\[\hat{y} = b_0 + b_1 x\]

  • \(\hat{y}\) (read “y-hat”) indicates the formula gives predicted values of \(y\)
  • \(b_0\) is the intercept
  • \(b_1\) is the slope

Understanding the coefficients

  • The slope (\(b_1\)) tells us how much \(y\) changes when \(x\) changes by 1 unit
  • The intercept (\(b_0\)) tells us the value of \(y\) when \(x\) is zero — often, this interpretation is a bit silly if \(x=0\) doesn’t make practical sense or falls outside the range of the data

Worked example. For the boiling point of water at different air pressures (\(n=17\)), \(b_0 = 155.3\) and \(b_1 = 1.90\), so the regression line is:

\[\widehat{\text{B.Pt}} = 155.3 + 1.90 \times \text{Pressure}\]

  • Slope: an increase in pressure of 1 inch Hg results in an increase of boiling point of 1.9°F
  • Intercept: when air pressure is zero, the boiling point is 155°F — but air pressure can’t be zero, so this interpretation is a bit silly

Making predictions. If air pressure is 21 inches of Hg, we predict a boiling point of:

\[\widehat{\text{B.Pt}} = 155.296 + (1.902 \times 21) = 195.24^{\circ}\text{F}\]

4.4 Residuals

The residuals are how much the predictions miss by. For each actual observation \(y\) (and given value of \(x\)), we can generate a prediction \(\hat{y}\) using the regression line. The residual for each observation is:

\[e = y - \hat{y}\]

Residual plots

  • Residuals should be completely random when plotted against the explanatory variable — no visible pattern
  • A curved residual plot suggests the relationship isn’t actually linear
  • A fanning residual plot (residuals spreading out or narrowing across the range of x) suggests the variability isn’t constant
  • We usually compute residuals for every observation and plot them against \(x\) to check the model is working OK

Worked example. For the leg-strength/kicking-distance data (\(n=13\)), the correlation is \(r = 0.865\) and \(R^2 = 0.749\) (74.9%): 74.9% of the variation in kicking distance is explained by the variation in right-leg strength. The residual plot for this example looks fine — a random display of points with no visible pattern.

Caution: the R given in SPSS/Excel’s Model Summary only gives the size of the correlation, not the direction — it is always shown as positive. Check the sign of the slope of the regression line to determine whether \(r\) should be positive or negative.

4.5 Cautions and Precautions

Regression is easy to use incorrectly. SPSS/Excel will compute a regression line for any two quantitative variables, but it may not be appropriate to do so.

Caution 1: Extrapolation. Predicting beyond the available data is very dangerous — we can’t be sure the linear relationship holds beyond the range we’ve actually observed. Never predict beyond the given data.

Worked example (Jessica’s height): the regression line \(\widehat{\text{Ht}} = 58.227 + 1.168 \times \text{Age}\) was fitted using data on a baby’s age (in months) and height. Extrapolating this line to age 21 (years, not months!) predicts a height of over 3.5 metres, and at age 30 almost 5 metres — an obviously absurd result of extrapolating far beyond the data.

Caution 2: Association is not causation. An association between two variables can be due to:

  • Causation — changes in one variable cause changes in the other, or
  • Confounding — the effect of a lurking variable that affects both measured variables but is itself not measured

Observational studies alone cannot demonstrate causality — in general, an experiment is needed. For example, over time both the number of university students in a town and the town’s crime rate might rise together, purely because both increase with the town’s growing population — time (or population growth) is the lurking variable, not a causal link between student numbers and crime.

More cautions

  • Outliers can make the regression line unreasonable
  • The data must be approximately linear
  • Both variables must be quantitative
